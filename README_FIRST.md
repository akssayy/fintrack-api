# Akshay's Backend Portfolio Projects

This bundle contains two starter repositories aligned with a Python backend internship:
1. `fintrack-api` — a personal finance REST API using FastAPI and SQLAlchemy.
2. `documind-lite` — a PDF text extraction and retrieval API using FastAPI.

## Important
These are functional MVPs, not claims of production readiness. Run them locally, test the endpoints, understand the code, and extend them before adding the projects to your resume. Do not claim features that you have not tested or implemented.

## Suggested order
1. Set up and run `fintrack-api`.
2. Test endpoints using `/docs` and add your own test cases.
3. Run `documind-lite`, upload a PDF, and try searching its extracted text.
4. Push each folder to its own public GitHub repository.
